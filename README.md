# DogFood T1 Core Frontend

Attractive React + Vite frontend starter for DogFood 2026 T1 Core.

## Run

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Pages

- Dashboard
- Events
- Create Event
- Teams
- Submissions
- Gallery
- Login

This is a frontend prototype. Backend authentication, database persistence,
role enforcement, deadline enforcement, and APIs still need to be connected.
